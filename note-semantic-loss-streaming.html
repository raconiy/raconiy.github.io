Semantic Fusion Before Memory Formation: A LingBot-Map Research Proposal

Research proposal · Explicit semantic fusion, causal memory, and controlled evaluation

在历史状态形成前融合像素对齐的语义，让语义沿共享注意力进入实际保存的 KV，再检验它是否改善后续几何。

At a Glance

  1. 主路径：RGB → 视觉 token 与轻量语义预测 → 门控残差融合 → LingBot-Map 共享上下文 → 几何与语义输出；各层缓存从融合后的表示形成。
  2. 三个训练目标：融合前语义蒸馏、上下文后语义输出监督、原有几何监督。教师仅训练使用；第一版不使用 memory reconstruction loss。
  3. 核心假设：在相同历史 token 配置下，正确对齐的语义能提高历史对后续几何的用途。需要区分语义、额外参数、额外监督和当前帧增强的贡献；尚无性能结果。

Research Proposal

01 · Problem, Mechanism, and Claim

任务是 RGB 流式重建：随着视频到来，持续预测几何和相机位姿，同时得到与几何对齐的语义特征。我们研究语义能否帮助一般连续场景中的历史利用，不限定为某件物体、特定运动方式或预设实例集合。

本版采用写入前融合：先从当前视觉 token 预测像素对齐的语义，再把它注入视觉表示，之后才进行帧内聚合、GCA 交互和缓存形成。这样语义有一条明确的前向路径进入历史 KV，而不是仅靠输出头的辅助 loss 间接影响主干。

当前能确定的是可实现的机制与实验定义，不能预先确定几何一定改善。待检验主张是：在匹配训练和缓存预算下，对齐语义参与历史形成，比只在输出端使用语义更有助于后续几何。若实验不支持，主张必须收缩。

02 · Figure 1: The Complete Forward Path

图中只包含一个重建主干。RGB 经图像编码器得到 x_t，轻量预测器 S 从 x_t 预测语义 s_t；x_t 和 s_t 经过门控残差融合得到 x̃_t，再进入原有帧内注意力与 GCA。几何头和上下文语义头从最终共享表示输出预测。

共享上下文形成各层的 Key/Value，按原规则存入历史缓存。当前帧随后成为近期历史；退出窗口后，保留该帧特殊 token 的 KV。未来帧读取的是这些受融合影响的表示。图中的缓存不是额外的语义字典，也没有独立语义重建网络。

下方教师与损失只在训练中使用。轻量语义预测器和融合模块在推理时仍运行，因为语义必须实际进入前向路径。此前版本的历史语义重建读取器已移出主架构。

Research Proposal

03 · What Semantic Information Contributes

语义来源是密集语言对齐教师的预训练知识。轻量预测器在 RGB 上学习近似这种表示：同一个局部区域除纹理外，还具有类别、部分属性及上下文上的相似性。它没有新增传感器观测，而是为视觉表示引入外部预训练先验。

我们提出两个可能作用：在外观变化时提供较稳定的区域线索；在共享注意力中帮助区分部分外观相近、语义不同的区域。它们可能帮助聚合与读取历史，但必须通过条件化实验检验，不能仅看特征可视化就断言对应正确。

语义没有给出精确深度、相机变换或实例身份。同类重复区域仍然可能混淆，粗区域特征也不能保证细边界。几何证据和原始视觉残差必须保留，模型不能仅按语义相似度合并三维表面。门控只是学习融合强度，不是已校准的语义可靠性。

Research Proposal

04 · How Semantics Enters the Actual Memory

融合发生在特殊 token 聚合图像信息之前。帧内注意力让 camera、anchor 与 register token 接触已经融合语义的图像 token；后续 GCA 继续用这些表示与历史交互。因此实际保留的 K/V 可以依赖 s_t。

写入接口是共享上下文对融合表示生成 KV 的过程，不是直接把 s_t 拼进一个外部文件。我们不新增历史 token，也不保存一份独立教师特征图。保留的向量是混合表示，不能直接给每个向量贴上对象名称或语义标签。

旧帧退出窗口时丢弃密集 token，留下此前已经生成的六个特殊 token 对应的 KV；不假定退出瞬间又运行一次新的压缩器。六个向量是否保留了足够语义，以及几何是否利用了这些语义，需要进一步测量。

第一版保留原缓存策略。每个旧帧六 token 仍随历史帧数增加，不称为严格固定总容量。比较时固定序列长度、锚点与窗口配置、层数、KV 维度和精度；另报告语义分支增加的参数与延迟。

Research Proposal

05 · Loss Placement and Gradient Flow

L_distill 加在融合前的 s_t：与冻结教师在同一像素/patch 位置的特征对齐。它确保进入融合模块的分支确实受到语义约束，而非一个任意新增 MLP。教师目标经过空间对齐和归一化，停止梯度。

L_out 加在 GCA 之后的上下文语义输出 s_out,t：让最终共享表示能输出语义。它可以监督当前帧输出，但不能单独证明旧历史含有语义。L_geo 保持基座的深度与位姿监督及尺度约定。

L_geo 的梯度从几何头经过共享上下文、融合门控和投影到 S；在可微序列展开内，也能通过被读取的历史 KV 回到过去帧的融合过程。L_distill 则约束 S 保持教师语义结构，避免其完全漂移成任意几何特征。

冻结教师和图像编码器；先训练 S 做蒸馏，再联合训练 S、融合模块、共享上下文 adapter 与输出头。冻结图像编码器仍允许后续层训练。初始化用弱注入保持基座稳定，避免把投影与门控同时置为使所有新路径无梯度的状态。

s*_t = stopgrad(normalize(Align(T(I_t))))
L_distill = mean_valid [1 − cos(s_t, s*_t)]
L_out = mean_valid [1 − cos(s_out,t, s*_t)]
L_total = L_geo + λ_d L_distill + λ_o L_out

L_geo → shared context → fusion → semantic predictor
L_geo(later) → historical KV → earlier fusion (if not detached)
Teacher: frozen; no L_mem in the first version

06 · Four Frames: Semantic Write Followed by Geometric Read

教学例子设近期窗口为两帧，F4 不属于锚点。相机连续经过建筑立面，F4 看到墙、窗框与入口；F5 到 F7 的视角和遮挡发生变化。这只是时间关系例子，不是限定应用场景或原模型超参数。

F4：预测 s4，并把它与 x4 融合。共享注意力形成特殊 token，各层写入 K4、V4。F5、F6：F4 仍处于近期上下文。F7：F4 的密集 token 已经退出窗口，仅保留特殊 token 的 KV，F7 的 GCA 可读取它们来预测当前几何。

在训练中，F7 的几何误差若依赖 F4 的历史读取，就能沿 GCA → K4/V4 → F4 上下文 → F4 融合模块回传，更新如何把语义用于摘要形成。若缓存被 detach，梯度到此中断，需要重算可微片段；展开长度要覆盖写入与使用。

关键区别：这版在 F4 前向编码时已经显式使用 s4。它不依赖“六个 token 能不能重建旧语义”的辅助任务来宣称语义进入了状态。损失负责训练语义质量与几何用途，实际融合由前向结构完成。

Research Proposal

07 · Claims and the Evidence Each Requires

第一层是机制：语义确实影响保存的 KV。固定 RGB 和其他输入，干预 s_t 后检查保留 KV 的变化，并确认几何损失到融合模块存在梯度。这只能证明路径存在，不能证明变化有益。

第二层是语义价值：正确对齐的语义比同预算额外 MLP、无语言视觉特征或破坏对齐的语义更有效。跨样本/空间打乱适合诊断模型依赖，也可能引入分布偏移，不能单靠这种损坏实验断言因果；需要对应重训消融支持。

第三层是历史用途：写入前融合要优于仅在最终解码特征中注入语义、且不把注入结果写回缓存的对照。还要按短历史、长间隔历史和未见环境评测，检查收益是否超出当前帧增强。

第四层才是最终效果：几何精度、完整度与轨迹指标在多个序列/随机种子上稳定改善，且额外开销可接受。不能因为语义分割提升就宣布几何提升，也不能只选有利场景或只报告均值。

ClaimRequired EvidenceWhat It Does Not Prove
Semantic write干预语义会改变实际保留 KV；梯度连通变化一定有益
Semantic value对齐语义优于匹配参数/监督的对照所有收益都来自语言

Geometric improvement精度、完整度、轨迹与统计稳定性普遍提升或超越所有基线

08 · Controlled Ablations: Is It Really Semantics?

各组共享几何训练数据、训练步数和缓存配置。能共享的语义头和蒸馏目标也保留，以避免把“有无额外监督”与“是否写入”混为一谈；清楚列出无法完全匹配的结构和计算差异。

核心比较 E 对 D：两组都有语义预测、监督和融合参数，D 仅在最后一次 GCA 之后、不会进入缓存的解码特征上融合，E 在上下文形成前融合。这个比较定位融合位置，而非证明语义天然优于所有视觉表示。

非语言教师控制应匹配空间分辨率、维度、训练预算并说明教师规模与预训练差异。它只能逐步缩小解释范围，不能声称已经完美隔离语言因素。正确语义与打乱语义的对照需保持特征幅度等统计尽量一致。

Research Proposal

09 · Testing the Historical Contribution

不能只在完整系统中关掉所有语义，因为那会同时损坏当前帧与历史。诊断历史作用时固定当前帧语义路径，干预旧帧语义形成的状态，观察后续几何如何变化。

可以用两次受控前向生成参考与干预缓存，再只替换指定旧帧条目，其余当前输入和参考缓存保持相同；这种混合缓存可能偏离训练分布，所以只作为敏感性诊断。同时训练一个禁止使用远期历史的匹配对照，检验主方案是否在可用远期历史时有额外收益。

在相同时间间隔、重叠范围和可见性条件下比较，避免把更容易的序列分配给某一组。可用冻结探针检查保留状态的粗语义可读性，但探针结果不是几何收益替代品。此前 memory reconstruction loss 仅作为后续可选实验，不进入本版总目标。

Research Proposal

10 · Expected Outcomes, Failures, and Reporting

目标输出为深度、相机位姿和密集语义向量，可累积成带语义特征的三维地图。与同一教师空间的文本向量比较可支持开放词汇区域查询；实例身份和跨帧实例分割需要额外关联机制，本版不承诺自动获得。

离线训练、遵循基座初始化的因果流式推理。教师和反向传播不在推理阶段运行；S、门控和投影保留，因此必须报告端到端延迟、显存、参数与离线教师成本。

预期语义在部分外观变化与区域混淆场景有帮助，但重复同类区域、错误伪语义和细结构也可能受损。报告深度/点云精度与完整度、ATE/RPE、跨帧一致性、语义指标和场景分组结果，并用多次训练或配对序列统计表达波动。

若 E 只优于 A、不能优于 D，只能说明融合有用，不能说改善了 memory；若 E 与 F 相当，只能说明高层视觉监督有用，语言语义的独特贡献尚未成立；若仅语义指标改善，就收缩为语义输出能力。

Research Proposal

11 · Novelty and a Defensible Research Statement

本方案的研究定位是语义参与历史表示形成：在流式历史预算受限的条件下，通过像素对齐的门控融合让语义进入实际缓存，再研究它对后续几何的作用。融合、门控和蒸馏本身都不是新发明，换一个基座也不自动构成充分创新。

候选贡献必须同时包含机制与证据：明确语义进入缓存的位置；在相同缓存配置下区别输出端融合与写入前融合；用语义及历史干预定位收益来源。若能识别原压缩策略在哪类条件下丢失有用区域线索，并稳定修复该问题，研究主张才更有分量。

当前汇报的准确表述是：我们提出并计划验证写入前语义融合，假设正确对齐的语义能改善历史表示对后续几何的可用性。不能写“已经证明语义必不可少”“首次实现”或“全面超过现有方法”。未来论文的结果性 claim 必须由上述实验填写。

Working hypothesis:
Pixel-aligned semantics fused before context formation can improve
the geometric utility of retained history at matched cache budgets.

Status: proposed mechanism; no empirical gain established yet.

12 · Connection to the Reading

ConceptFusion 帮助定义像素对齐开放词汇特征及地图输出，但主要是特征附着与融合。SLARM 启发重建中的语言监督；LingBot-Map 提供要介入的实际缓存结构。SNI-SLAM 与 SemGauss-SLAM 的原文提醒我们：语义 loss 存在不代表几何梯度和收益成立。

本版的关键区别是前向连接可追踪：S(x) → 融合图像 token → 特殊 token 聚合 → 缓存 KV → 后续 GCA → 几何。下方保留四篇论文的原图、消融与输入条件，作为机制背景，不将它们的数字迁移成我们的结果。

13 · Scope and Reading Versions

这四篇是用户指定的基础文献，不作为近期新论文介绍。它们多数使用 RGB-D 和逐场景在线优化，而 LingBot-Map 的迁移目标是学习式 RGB 流式重建。可以借鉴监督机制，不能直接照搬输入条件、速度或精度。

这里区分三个问题：输出是否有语义；语义损失是否改变几何预测；有限历史状态是否因语义监督而更有用。三个问题需要不同对照实验。

14 · ConceptFusion: Features Attached to Geometry

沿原图，先对当前 RGB 提取全图及区域 CLIP 特征，再把区域信息组合成像素对齐特征。类别无关分割提供区域，而不是先限定一组类别再分类。全局特征保留上下文，局部特征提供较细的区域区别；区域重叠时还需要融合与归一化。

之后依赖深度、相机位姿和几何一致性，将当前像素对应到地图点，融合颜色与语义向量。公式中的 c 是历史融合权重，α 是当前观测权重。这里的空间对应先由几何建立，语义向量不是直接拿来替代相机变换。

文本查询编码到同一特征空间后，可以检索三维区域。它说明如何得到开放词汇地图，但没有通过训练语义 loss 改善几何。它适合作为“已有几何上附加语义”的对照。

f_new = (c_old · f_old + α · f_pixel) / (c_old + α)

15 · ConceptFusion: Evidence and Computational Boundary

UnCoCo 的 structured text query 评测中，ConceptFusion 的 3D mIoU 为 0.378，LSeg-3D 为 0.122，OpenSeg 为 0.153。这是语义检索与分割指标，不能解读为重建误差下降。数据集包含 20 段 RGB-D 序列、78 个物体，其中 2 段用于参数选择。

论文的基础建图速度与语义特征提取开销分开报告；离线特征提取约需 10–15 秒/图（RTX 3090）。不能只摘建图帧率，把整个语义系统说成实时。稠密高维特征也会增加地图内存。

Paper Analysis

16 · SNI-SLAM: Joint Features Do Not Imply Joint Gradients

原图将几何、外观和语义特征放到统一融合过程：几何编码作为 query，外观作为 key，语义作为 value，通过交叉注意力产生融合信息。三维地图采用分层特征平面，解码颜色、语义和截断符号距离。DINOv2 用于视觉特征提取；它不是图文对齐的 VLM。

必须分清两个监督：语义分类使用交叉熵；特征级 L1 监督约束提取特征与地图插值得到的特征。论文明确对语义分类 loss 做梯度截断，避免其干扰几何和外观。因此，“SNI-SLAM 证明语义交叉熵直接改善几何”是不准确的。

特征融合和特征级监督可以改变共享表示的学习，但不能把整个系统收益都归到语义 CE。符号 f_extract 表示提取并融合的目标特征，f_interp 表示地图插值得到的特征。

L_feature = ||f_extract − f_interp||₁

18 · SemGauss-SLAM: Where Semantics Reaches Geometry

原图先从 RGB-D 建立带语义向量的高斯地图。冻结 DINOv2 提供密集视觉特征目标，渲染特征与目标做 L1 对齐，语义解码器再预测标签。地图优化还包含 RGB、深度和语义分类监督。

关键连接出现在 semantic-informed bundle adjustment：把共同可见关键帧中的语义渲染，利用深度和相机变换重投影到另一视图，对齐同一表面的语义，并联合调整地图与位姿。变换作用于三维点和采样位置，不是把旋转矩阵直接乘到语义向量上。

常规 tracking 使用 RGB 与深度残差，不能笼统地说每个跟踪步骤都有语义 loss。语义特征蒸馏与语义 BA 是两个不同机制。

20 · SGS-SLAM: Semantic Rendering Residuals

沿原图，高斯同时保存颜色、几何与语义颜色，按相同的可见性和混合权重渲染 RGB、深度与语义图。这里的语义颜色是标签表示，不是开放词汇 CLIP embedding。

跟踪时固定地图，用渲染与观测的残差调整位姿；建图时固定当前位姿，更新高斯参数。语义渲染误差能通过投影和混合权重关联到几何，因而比“在固定地图上训练分类头”更接近几何约束。

关键帧筛选同时考虑几何重叠与语义冗余：高语义重叠不一定意味着应优先保留，也可能意味着重复。这个选择策略与语义 loss 都会影响最终系统表现，需要分别消融。

21 · SGS-SLAM: What the Numbers Support

Table 4 在 ScanNet scene0000_00 上，移除语义通道后 Depth L1 为 9.15 cm、ATE 为 13.81 cm；完整系统为 6.18 cm、11.26 cm。相同表里移除深度通道会显著恶化，说明语义并不能取代几何证据。

Discussion

Reading Questions

Is semantics actually in the memory?

存在明确前向依赖：语义影响上下文表示和实际保存的 KV。但保留多少语义、是否被几何利用，仍需诊断和消融。

Which losses are used?

融合前 L_distill、上下文后 L_out、原有 L_geo。第一版不使用 L_mem。

What would establish a memory benefit?

写入前融合优于同预算输出端融合，并在受控历史消融和多序列几何评测中体现额外收益。

Can we already claim semantics improves geometry?

不能。机制已明确，实验未完成；当前只能提出可证伪假设。

Is the extra branch needed at inference?

轻量语义预测器和融合模块需要，冻结教师不需要。因此推理成本必须实测。
