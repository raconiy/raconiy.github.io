Semantic Fusion Before Memory Formation: Research Brief

Ten-minute research briefing · Proposed method, not experimental results

围绕一个问题展开：语义在历史状态形成前参与融合，能否改善后续几何？以下六部分是可直接使用的汇报正文，总时长约十分钟。

At a Glance

  1. 研究目标：让 LingBot-Map 的流式历史状态包含显式融合的语义，并检验后续几何收益。
  2. 方法主线：轻量语义预测 → 写入前门控融合 → 共享上下文与原有缓存 → 后续几何预测。
  3. 证据要求：优于输出端融合和同预算普通特征分支；几何精度、完整度与开销一起报告。

Spoken Briefing

01 · Research Question and Motivation — 1 min

今天我汇报一个基于 LingBot-Map 的研究方案：在历史状态形成之前融合语义，研究它能否改善流式重建。输入仍然是连续 RGB，输出是每帧深度、相机位姿和语义特征。训练离线进行，推理按基座的初始化和因果规则逐帧运行。

切入点是历史压缩。LingBot-Map 保留锚点和近期密集窗口，较旧帧只留下六个特殊 token 的 KV。原来的几何监督会训练这些摘要，但我们想问：如果摘要形成时已经结合区域语义，后面的帧能不能更有效地利用历史？

因此，研究重点是语义对历史几何用途的影响。我们不先假设它必然有效，也不把增加语义输出等同于改善重建。当前完成的是架构和验证方案，还没有性能结果。

Spoken Briefing

02 · What the Prior Work Establishes — 1 min

已有工作给了我们三个直接启发。ConceptFusion 说明，预训练的开放词汇特征可以对齐到像素，再融合进三维地图；但把语义附着到地图上，并不能证明语义改善了几何。SLARM 启发我们用密集语言特征监督重建表示，但它的输入和表示与 LingBot-Map 不同，不能原样搬过去。

最重要的证据来自语义 SLAM 的消融。SemGauss-SLAM 在 room0 上移除特征损失，mIoU 从 92.81 降到 83.60，但对应的轨迹和深度误差没有变化；移除语义 BA 才出现几何退化。SNI-SLAM 也明确截断语义分类损失对几何和外观的梯度。

这说明不能仅凭“有语义 loss”解释几何提升。我们的设计必须明确两件事：语义在前向中怎样进入实际缓存，以及后续几何怎样使用这份缓存。

Spoken Briefing

03 · Figure 1: Semantic Fusion Before Memory Formation — 2 min

沿 Figure 1 上半部分从左到右看。当前图像先经原有编码器得到视觉 token x。一个轻量语义预测器 S 从同一份视觉特征预测像素对齐的语义 s。它不是第二套重建网络，训练时由冻结的密集语言对齐教师监督，部署时只运行这个轻量预测器。

我们在进入共享上下文之前，把 s 投影到主干维度，与 x 做门控残差融合。原视觉特征完整保留，门控学习语义注入强度。这里的门控不能直接解释成可靠性置信度。语义提供的是预训练区域先验，而不是新的深度观测。

融合后的图像 token 再进入帧内注意力和 GCA。特殊 token 在聚合图像信息时就已经能够接触语义，各层由这些表示产生 Key 和 Value。接着仍按 LingBot-Map 原有规则保存近期信息和旧帧摘要。

因此语义进入 memory 的路径是：语义预测、融合图像 token、特殊 token 聚合、历史 KV。未来帧通过原有 GCA 读取这些 KV，再输出深度和位姿。语义保存在混合向量里，不是额外存一份类别标签，也不是把六个 token 分成六个物体。

这版保持历史 token 数量和保留规则不变，只研究写入内容是否更有用。旧帧每帧六 token 仍会随序列长度增长，所以不能声称严格固定总内存。语义分支增加的参数与推理时间也会单独报告。

s_t = S(E(I_t))
x̃_t = x_t + g_t ⊙ W_s s_t
(x̃_t, historical KV) → shared context → geometry / semantics + new KV

Spoken Briefing

04 · Losses and the Historical Gradient Path — 2 min

看图下半部分，第一版使用三个损失。融合前的 L_distill 对齐语义预测和冻结教师，确保注入的信息受到语义约束。上下文后的 L_out 监督最终语义输出。L_geo 沿用原来的深度与位姿监督，负责判断这些信息是否有几何用途。教师目标停止梯度；主方案不再使用之前讨论的 memory reconstruction loss。

用连续帧说明历史路径。假设近期窗口为两帧，仅作为讲解。F4 先预测语义、融合视觉特征，并形成它的特殊 token 和 KV。F5、F6 还能读取 F4 的密集信息。到 F7，F4 的密集 token 已被丢弃，只剩旧帧摘要；F7 的 GCA 仍可以读取这份摘要。

训练中，F7 的几何误差沿几何头、GCA 和 F4 的 KV，回传到 F4 的共享上下文与融合模块。这样，模型学习的不是单纯保存更多语义，而是怎样把语义用于后续几何。当前帧的语义蒸馏同时约束 S，防止它完全变成没有语义含义的普通分支。

这里要求训练片段覆盖历史写入与后续读取，并保留可微计算图。如果缓存已经 detach，就不能训练到过去的融合过程。优化器更新的是产生这些状态的网络参数；推理时参数固定，不调用教师，也不做在线反向优化。

L = L_geo + λ_d L_distill + λ_o L_out
L_geo(F7) → GCA → KV(F4) → historical context → fusion(F4)

Spoken Briefing

05 · Claim and Decisive Experiments — 3 min

我们希望检验的核心主张是：正确对齐的语义，在历史状态形成前参与融合，可以提高压缩历史对后续几何的可用性。预期作用有两个：在外观变化时提供较稳定的区域线索；帮助区分部分外观相近、语义不同的区域。它不等于精确三维对应，同类重复区域仍可能混淆，所以几何与视觉证据不能被替代。

这个主张不能只用“完整系统比原模型好”证明。第一组对照控制额外能力：匹配微调预算的原模型、同规模普通特征分支、以及非语言视觉教师监督。我们要知道收益究竟来自语义，还是额外参数、训练或一般高层特征。

第二组是决定性对照：输出端融合与写入前融合。两组都具有语义预测和监督，前者只在最后 GCA 之后融合，结果不写入缓存；后者在上下文形成前融合。如果后者不能进一步改善后续几何，就不能声称语义改善了 memory。

第三组检查正确语义是否重要。保持当前帧路径不变，干预旧帧的语义或历史条目，观察未来预测；也比较正确对齐与打乱的区域特征。但打乱会产生分布偏移，所以它只作为诊断，还要结合对应重训的对照，不能把一次破坏实验当成充分证明。

指标同时报告几何精度、完整度、轨迹、跨帧一致性和运行开销，并在未见场景、不同历史间隔及多个序列上比较。不能删掉困难点后只说精度提高。如果只有分割提高而几何不变，结论就收缩为语义输出能力；如果只优于原模型、不优于输出端融合，就不能主张历史收益。

所以我们真正要建立的是一条证据链：语义影响实际缓存，正确语义优于普通额外特征，写入前融合优于仅增强当前输出，最后才是稳定的几何收益。这几步连起来，才能支持语义的重要性。

Spoken Briefing

06 · Contribution and Immediate Next Step — 1 min

目前的候选贡献是明确语义参与流式历史形成的位置，并通过受控实验解释它的几何用途。门控、蒸馏和增加语义头本身并不新；只有证明写入前融合在相同缓存配置下带来额外历史收益，这个方向才有足够清楚的研究价值。

实施上先复现同预算几何微调，再加入轻量语义蒸馏，最后实现输出端与写入前两种融合。优先做这对核心实验，确认收益位置之后，再考虑更复杂的 memory 策略。输出是几何与对齐语义，开放词汇查询可以建立在它之上；实例关联和动态分解不放进第一版。

因此今天提出的是一个可实现、可证伪的方案：让语义在写入前进入历史，并检验它是否帮助未来重建。下一步最重要的结果不是更大的架构，而是写入前融合相对输出端融合的受控证据。

Discussion

Reading Questions

Why not simply add a semantic output head?

输出头提供语义能力，但没有明确的前向语义回注路径。监督本身也可能改变共享特征，所以需要“仅监督”与“显式融合”对照，而不能假定前者完全无效。

How is the novelty different from ordinary feature fusion?

普通融合本身不足以作为新颖性。候选贡献是流式压缩位置上的设计及其后续几何证据，目前尚未得到实验支持，也未完成首创性检索。

Does the gate tell us whether semantics is reliable?

不直接代表可靠性。它是可学习的注入强度，是否抑制错误语义需要干预与评测。

Can the six tokens preserve detailed semantics?

容量是否足够尚不确定。当前不要求它们恢复完整分割，只检验保留信息是否对未来几何有用；固定探针可作为辅助诊断。

What would falsify the central claim?

写入前融合不优于输出端融合，或收益完全被同预算普通特征解释；这些结果会削弱语义改善历史的主张。
