Paper Notes

Task and Interface

SpaceMCP 研究用 MCP 工具把基础空间感知能力暴露给 VLM，使模型能够调用对象检测、深度、坐标和关系查询，再组合这些原语完成空间推理。

输入是图像、语言问题和工具上下文；输出是带证据的空间回答。

Paper Notes

Tool-Based Spatial Memory

系统把 perception primitives 作为外部可查询状态，VLM 通过工具读取几何和语义片段，而不是单靠视觉 token 记忆。

这种接口把 memory read 变成显式工具调用；查询结果可以包括对象位置、距离、方向和可见性。

Paper Notes

Experiments

论文报告在空间任务中，将几何原语与 VLM 推理结合能解决更复杂的空间关系。具体数值和基线必须以论文表格为准，本笔记只保留方法层结论，避免把工具调用成功当成重建精度。

Source: Paper / Official Implementation ↗

Paper Notes

Relation to LingBot-Map

对 LingBot-Map，SpaceMCP 提供了一个可解释的下游接口：memory 不只输出深度，也能被查询为对象/区域/关系证据。

语义融合是否改善重建，仍需看未来帧深度、点云和轨迹；工具接口本身只能说明查询可用。

Source: Paper / Official Implementation ↗

Paper Notes

Limits

这是空间推理和工具接口工作，不是新的流式三维重建模型。其证据对我们的价值在于定义可诊断的 memory read，而不是直接提供几何训练 loss。

Source: Paper / Official Implementation ↗

Discussion

Reading Questions

Is SpaceMCP a reconstruction model?

不是，它是工具化空间推理接口。

Why is it relevant?

它把 memory read 变成可检查的对象/关系查询。

What should be measured in LingBot-Map?

查询准确率之外，要测未来帧深度、点云和轨迹。
