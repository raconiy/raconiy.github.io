Geospatial Vector Geometry as a Native Spatial Modality for Vision-Language Models

First submitted 2026-10-12 · Reading version 2610.16769v1

GeoVec-VLM 将结构化 vector geometry 作为 VLM 的原生空间模态，并让几何表示与视觉、语言按查询关系交互。五类空间推理任务中，相对最强基线平均提升约 11%，且在 geographic transfer 中保持收益。

At a Glance

  1. 保留 vector 的拓扑和排列结构，而不是序列化成普通文本。
  2. 几何与视觉/语言按查询关系交互。
  3. 结果支持显式空间模态，但不是三维重建 memory。

Paper Notes

Problem and Representation

大尺度地理推理中，视觉观察稀疏，语言描述又难以提供精确空间参照。GeoVec-VLM 将 vector objects 编码为结构化几何表示，保留位置、形状、拓扑和排列。

输入是 vector geometry、视觉内容与语言查询；输出为地理空间推理结果。

Paper Notes

Geometry Interaction

模型让几何表示进入 multimodal computation，并根据查询关系与视觉和语言状态交互。关键不是把 GeoJSON 当长文本，而是保持几何关系可计算。

Paper Notes

Experiments

论文在五类空间推理任务比较多个基线，GeoVec-VLM 相对最强基线平均提升约 11%，并在 geographic transfer 中保持增益。几何打乱实验会显著降低空间一致性，说明模型依赖结构。

Source: Paper / Official Implementation ↗

Paper Notes

Transfer to LingBot-Map

对 LingBot-Map，这启发我们把 object/region memory 表示成保留空间关系的结构化状态，而非只保存独立语义向量。

但地理 vector 与室内流式 pointmap 不同，不能直接迁移数值。应先定义对象中心、可见性、邻接和深度关系，再测试它们是否改善 memory read。

Source: Paper / Official Implementation ↗

Paper Notes

Limitations

论文的任务是地理空间 VLM 推理，不是在线三维重建；其收益不能直接证明语义改善几何。

Discussion

Reading Questions

Is vector geometry just text?

不是，方法保留结构并让其参与多模态交互。

Does it update a streaming map?

不直接，它提供空间模态而非长期重建 memory。

What can we borrow?

保留语义对象之间的空间关系，让 memory 查询读取结构化证据。
