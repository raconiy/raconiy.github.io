OpenSplatGraph: Reliable Semantic Fusion and Persistent Object Graphs

First submitted 2026-10-06 · Reading version 2610.07569v1

OpenSplatGraph 从 RGB-D 观测建立混合 TSDF–Gaussian 地图，并把查询得到的对象维护为持续存在的场景图节点。它用语义观测次数、置信度和跨帧分歧评价对象候选，再结合几何关联与关系推理完成定位。在线 ScanNet20 分割的 mIoU 从 OpenGS-Fusion 的 27.09 提高到 36.75，但这些结果尚不能证明几何重建本身得到改善。

At a Glance

  1. 语义保存在体素场，Gaussian 承担细节与渲染，不能概括成每个高斯一个 CLIP 向量。
  2. 查询生成候选对象，持久 ID 使图节点不必每次重新建立。
  3. 分割收益、关系定位收益和几何收益需要分别验证。

Paper Notes

Problem and Representation

研究对象是在线开放词汇机器人感知：输入带位姿的多视角 RGB-D 序列和后续自然语言查询，输出稠密语义地图、查询对应的对象实例以及持续积累的场景图。开放词汇指查询使用语言编码器表示，不局限于训练时固定分类头；并不意味着实例身份可以只靠类别决定。

底层继承 OpenGS-Fusion 的混合表示。稀疏 TSDF 体素用于几何与语义增量融合，每个体素关联一组 Gaussian；高斯用于细节表达和渲染。体素保存语言特征 F、观测次数 c、累积置信度 w 和位置 X，而不是将整个系统描述为纯 Gaussian 语义优化器。

本次阅读版本首次公开于 2026-10-06，超出最近三十天，因此按九十天窗口补选；官方项目页标注 ACCV 2026 accepted。选择理由是它直接讨论语义融合可靠性与物体持久关联，可补足近期 memory 论文对显式地图表示的覆盖。

Reading the Original Architecture

Figure 2 的入口是 RGB-D 流。SAM 将图像划成区域，OpenCLIP ViT-B/16 给区域提供语言对齐特征；通过深度和位姿将观测纳入体素语义场。真实机器人实验用 MobileSAMv2 替换 SAM，位姿来自 ORB-SLAM3。

当查询 q 到来时，文本编码器生成 e(q)，与所有体素特征计算余弦相似度。阈值筛选之后，在三维坐标上用 DBSCAN 找空间连通候选；每个候选得到中心、轴对齐包围盒、平均相似度和可靠性评分。候选再与已有实例关联，复用持久 ID 或创建新节点。

节点之间先用中心和包围盒推断 near、on/under、inside 等关系。需要更丰富语义时，再从带实例 ID 的渲染关键帧调用 VLM，并跨视角投票保留关系。VLM 关系增强可以异步进行；它不在论文描述中直接修改 Gaussian 的位置或深度。

Semantic Fusion and Reliability Statistics

公式 (1) 的细节很重要：历史特征的权重是观测次数 c，新特征 f 的权重是该次置信度 ω；更新后 c 加一，w 累加 ω。它不是常见的用累计权重 w 同时出现在分子和分母中的置信度加权平均。论文明确采用这种混合权重，因此复现时不应自行替换公式。

教学算例：已有 c=4 次观测，新观测 ω=0.2，则新特征的系数只有 0.2/4.2≈4.76%；如果 ω=1，则为 20%。这是新观测对表示影响的比例，不是预测正确的概率。由于历史项按次数增长，大量低质量观测是否使旧信息过强，需要另行验证。

在融合之前计算新旧向量的归一化余弦分歧，并用衰减系数 0.9 的指数滑动平均更新 r(v)。对象置信度 C 同时使用区域平均累计置信度和平均分歧：前者经 tanh 饱和，后者裁剪到 [0,1]。λ=0.6，κ=5。r 初始为零，因此单次观测的低分歧不能当成已经通过多视角验证。

C 只用于候选对象排序和过滤，未做监督校准；它应被理解为启发式可靠性分数。语义一致可能意味着标签稳定，也可能是教师持续犯同一种错误，故不能把它作为几何正确性的替代指标。

Fᵥ ← (c(v)Fᵥ + ωᵥfᵥ) / (c(v) + ωᵥ)
c(v) ← c(v) + 1;  w(v) ← w(v) + ωᵥ
C(Vₖ) = λ tanh(meanᵥ[w(v)] / κ)
          + (1 − λ) clip(1 − meanᵥ[r(v)], 0, 1)

Query Extraction, Identity, and Relations

DBSCAN 的邻域半径是 1.5 倍体素边长。论文采用 0.05 m 体素，因此半径为 0.075 m；最少邻居数为 5，小于 10 个体素的簇被丢弃。候选排序联合语义相似度和可靠性，语义相似度优先，簇大小用于打破平局。这些阈值会影响细小对象与相邻对象的分离，不能只报告最终查询成功案例。

实例关联先限制为同一语义标签，再在 0.35 m 内找最近、尚未匹配的旧中心，一对一复用 ID。这个机制是轻量的几何语义匹配，不是学习到的跨视角实例表征。同类相邻对象、部分可见导致中心偏移，以及同义词标签变化，都是需要测试的边界条件。

空间关系由几何规则在线更新；开放语义关系由 GPT-4o-mini 对最多三十张关键帧预测有向三元组，至少获得三票才保留。边置信度是正向预测数除以两对象共同可见的视图数。因此三票与置信度是两个概念，多视角一致也不是人工真值。

图不是完整的、查询无关对象目录。对象随查询被提取并加入图；没有被问到的对象可能仍只有稠密特征，没有节点。持久图减少重复建图的开销，但这一表示也会受查询顺序和覆盖范围影响。

Training, Runtime, and Experimental Protocol

新增部分主要是预训练感知特征、增量统计、聚类和图维护。论文没有给出一个把关系推理或可靠性损失反传到 Gaussian 几何的联合训练目标。底层高斯建图与开放词汇语义融合是系统组成部分，但不能从“联合维护地图和图”推导出“端到端联合学习”。

分割在 ScanNet 与 Replica 上使用 mIoU、mAcc，并将 Replica 的 88 类映射到 ScanNet20 和 NYUv2-40。不同映射的数字需要分别比较。表中还列出在线 FPS；OpenSplatGraph 在 ScanNet 为 1.20，对照 OpenGS-Fusion 为 1.22。这里不能把离线 Gaussian 方法的分割分数直接解释为同一延迟预算下的优劣。

对象定位采用 ConceptGraphs 的 Replica 查询与协议，分为描述、可供性和否定三类，分别使用 CLIP 检索和 LLM 检索并报告 Recall@k。Table 2 的 ConceptGraphs 数字来自其论文，而非本文统一重跑。真实机器人演示包括导航和抓取，但正文没有足够的成功率与试验次数支持对泛化机器人性能作强结论。

What the Results Establish

下表摘录 Table 1 的 ScanNet20 映射。在线分割收益在 ScanNet 较大，在 Replica 较小；不能把某一个数据集的增量推广到所有场景。离线 InstanceGaussian 在 ScanNet 的 mIoU 为 40.32，高于本文 36.75，但输入流程与处理模式不同。

Table 3 的逐步消融显示，可靠性建模使 mIoU 从 30.97 升到 36.06、mAcc 从 42.39 升到 50.74；加入持久关联不再改变这两项，图关系推理使 R@1 从 0.36 升到 0.50。该表的设置描述不足以将 36.06 直接当成 Table 1 某个单独数据集分数，应分别引用。

定位并非全面提升。CLIP 描述类 R@1 从 ConceptGraphs 的 0.59 降到 0.45，但可供性由 0.43 升到 0.54、否定由 0.26 升到 0.51。LLM 描述类 R@1 同样从 0.61 降到 0.50；否定类 R@1 都是 0.80。关系表示对某些问题有效，但不保证最直接的描述查询也更好。

附录直接图评测中，节点 precision 为 0.73 对 0.71，边 precision 为 0.91 对 0.88，重复节点率为 5.94% 对 6.77%。这些结果支持图质量与身份维护的改善；仍缺少重复运行波动、完整几何精度与总存储曲线，不能据此宣称语义已经提升真实几何。

Paper Notes

Connection to Semantic Streaming Memory

这篇工作能支持一个较窄但清楚的判断：多视角语义证据的可靠性值得显式维护，且稠密场与实例身份可以服务不同查询需求。它没有证明开放词汇特征只要融合到地图中，就会改善位姿或表面形状。

对 LingBot-Map，最直接的借鉴是给写入前融合的语义证据增加跨帧一致性统计与来源信息，控制不可靠语义对历史状态的影响；但跨帧对应必须先由几何与可见性验证，不能以类别相似度作为同一表面的证据。统计量可以是门控输入或分析工具，而非直接复制它的体素公式到六个摘要 token。

若尝试高斯下游，先用预测几何建立显式地图，再比较“仅附加语义”和“语义参与地图优化或前端预测”两种版本。要把收益归因于几何反馈，必须说明哪些参数接收语义损失梯度，同时报告几何精度、完整度及总存储。以上是迁移实验设计，当前没有已完成的实验结果。

与 AgiWorld 合读可得到互补约束：语义统计回答历史内容是否稳定，可见性回答该内容是否属于当前要读的表面。两者均不能独立替代真实观测和几何验证。

Discussion

Reading Questions

Where are the semantic features stored?

本文的语言特征与可靠性统计主要存在稀疏体素中，每个体素关联 Gaussian。语义场和高斯细节表示共同组成混合地图。

Does the graph contain every object?

不保证。对象由查询条件提取，并逐步积累为图节点；稠密场覆盖的区域可以还没有对象节点。

Is geometric improvement demonstrated?

没有充分证据。主要量化结果是分割、对象定位和图质量；未给出语义反馈使深度、位姿或几何完整度改善的受控结论。
