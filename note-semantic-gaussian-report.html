Semantic Gaussian Reconstruction with LingBot-Map

Research report · Prepared October 26, 2026 · Literature analysis and proposed experiments

研究目标是让语义同时成为三维表示的属性和几何估计的约束。报告比较语言特征蒸馏与语义几何联合优化，并给出迁移到 LingBot-Map 的接口、训练路径和实验判据。

At a Glance

  1. 路线 A：在固定高斯几何上学习语言特征，建立可查询的语义地图和必要对照。
  2. 路线 B：通过跨视角语义渲染约束位置、位姿与共享表示，再检验写入前融合是否改善历史利用。
  3. 当前完成文献核对、接口设计和合成梯度检查；模型训练、真实序列效果与性能结论均待验证。

Research Analysis

01 · Research Question and Scope

目标是以 RGB 视频为输入，增量输出相机位姿、深度以及带语义的三维表示，并研究语义能否改善后续几何估计。问题不是地图是否能够显示类别颜色，而是额外语义先验是否改变了几何证据的组织、关联或优化。

目前没有完成 LingBot-Map 训练、语义高斯集成或真实序列评测。本阶段可以汇报的工作是：两类方法的机制比较、基座接口和梯度路径设计，以及一个可复现的合成数值检查。后续尝试均以下文实验协议为准。

本文选择两条互补路线：语言特征蒸馏用于建立语义地图；跨视角语义几何联合约束用于检验几何收益。前者是后者的表示基础和对照，避免同时引入多条主线。

Research Analysis

02 · Method A: Language Features on Gaussians

参考 LangSplat。一个普通高斯保存中心 μ、协方差 Σ、不透明度 α 和颜色 c；语义扩展再增加向量 z。SAM 提供区域，CLIP 提供图文对齐特征，区域特征赋给对应像素后形成监督目标。SAM 本身不提供语言语义，整图 CLIP 向量也不能直接当作密集像素特征。

渲染时用与颜色相同的投影及透明度权重混合 z，得到二维特征图，再与教师对齐。LangSplat 用逐场景自编码器压缩语言表示，并处理 whole、part、subpart 多层语义；这里借鉴的是“特征作为高斯属性，经可微渲染接受二维监督”。

我们的 A 组明确固定高斯几何和位姿，只学习 z 与必要解码器。这是为归因设置的实现约束，不把它描述为所有语言高斯方法的统一训练方式。输出可与文本编码比较，支持开放词汇区域查询；不能直接推出持久实例 ID。

优点是语义能力容易检查，且不会让不可靠教师改坏几何。局限也清楚：几何固定时，该损失不可能改善几何。直接将这条路线命名为“语义引导重建”会超出证据。

迁移到未见场景的流式系统时，不能预先用整段测试视频训练逐场景自编码器。第一版可离线学习并冻结共享投影，保持所有时刻的 z 在同一空间；压缩质量需另行验证。

G_i = (mu_i, Sigma_i, alpha_i, color_i, z_i)
w_i(p) = a_i(p) * product_(j<i)(1-a_j(p))
F_render(p) = sum_i w_i(p) z_i
L_feature = sum_p q(p) rho(F_render(p) - stopgrad(E_teacher(p)))
Method A: geometry and poses fixed; optimize semantic attributes only.

Research Analysis

03 · Method B: Semantic Residuals That Reach Geometry

参考 SemGauss-SLAM 的跨视角语义 BA，并以 SGS-SLAM 的语义通道作为补充。核心区别是让损失依赖高斯投影和跨帧对应，而不仅依赖语义向量。若一个区域投影到错误位置，会与该位置的教师特征冲突，从而为位置或位姿提供修正方向。

给定源帧像素 p，利用深度、内参与相对位姿计算目标像素 u。比较源区域特征与目标图在 u 处采样的特征；还需共视、遮挡和置信度过滤。旋转和平移作用于三维点及采样位置，不能直接乘到语义向量上。

我们提出的 B 组可采用跨视角渲染教师监督：源帧预测高斯，在另一已知训练视角渲染特征，与该视角冻结教师对齐。这个版本不同于简单复述原论文的 BA 方程，它适合连接前馈预测网络。源帧不得读取目标图后再完成监督任务，否则可能形成复制捷径。

当渲染权重 w_i 依赖 μ、Σ、α 和位姿 T 时，梯度可经过权重进入几何；若权重或这些参数被 detach，则只剩语义属性学习。若 z 可以随意改变，也可能由特征吸收错误、几何不动，因此需先稳定语义表示，再谨慎开放几何，并保留原几何及 RGB 约束。

语义作用是提供部分区域的可区分性和跨视角稳定线索，不提供精确深度。同类重复物体、区域内部近乎恒定的特征、错误掩码和动态遮挡都会削弱甚至反转梯度。不能把同类视为同实例，更不能把一个物体内部强制平滑成平面。

u = project(K_j T_(j<-i) [D_i(p) K_i^-1 p])
L_cross = sum_(i,j,p) q_ij(p) rho(F_i(p) - F_teacher,j(u))
dL/dmu_i includes (dL/dF_render) * z_i * (dw_i/dmu_i)
Visibility weights q are treated as fixed masks within each update.
This is a proposed adaptation; not a claim about an uninspected code path.

04 · What the Published Ablation Actually Shows

SemGauss-SLAM v4 的 room0 消融值得作为论证核心。去掉 feature-level loss 后，mIoU 为 83.60，完整系统为 92.81，但轨迹 RMSE 与 Depth L1 都保持 0.26 cm 和 0.54 cm。作者明确说明这条特征 loss 只优化语义特征。

同论文 Table VI 单独去掉 BA 的语义约束，room0 的轨迹 RMSE/Depth L1 为 0.35/0.66 cm，完整系统为 0.26/0.54 cm。Table V 去掉整套 semantic-informed BA 则是 0.35/0.70 cm；两组不能混写。

这些结果支持的判断是：语义监督存在与语义约束几何不是一回事，必须核对具体反馈路径。它们来自 RGB-D、逐场景优化和特定场景消融，不能当作 RGB-only LingBot-Map 的预期增益。DINOv2 特征本身也不是开放词汇文本空间。

Research Analysis

05 · The Interface to LingBot-Map

LingBot-Map 的原生输出是位姿与密集深度，不是高斯场。新增高斯表示至少需要由深度和内参反投影得到中心，再初始化尺度、旋转、不透明度和颜色，并处理跨帧重复、可见性和新增区域。把点云简单改成高斯文件不等于已经得到可靠可渲染地图。

第一层实现可以完全冻结 LingBot-Map：用其几何初始化局部高斯地图，分别运行 A 的特征学习和 B 的局部联合优化。A/B 共享高斯数量、视图、优化步数及 RGB/几何约束，隔离语义梯度作用。这能验证地图后端是否受益，但不能说明网络 memory 已改善。

若研究主线仍是 memory，第二层才接入写入前融合：图像 token x 经小语义预测器得到 s，投影并门控残差融合为 x_tilde，再进入帧内注意力和 GCA。未来缓存沿用原保留规则。语义由此影响保存的 KV，而不是放在完全独立的对象字典里。

高斯头从共享输出预测 z 及必要高斯属性，中心由网络深度可微反投影得到；它承担跨视角训练读出。为使监督真正到达 memory，不能通过导出点云、离线文件或 detach 后的地图连接损失。离散选点与新增操作可固定在一次展开内，但连续深度、位姿和特征路径必须可微。

这里有两种不同的记忆：网络 KV 是未来预测上下文，外部高斯地图是累计场景表示。后端地图改善不会自动写回 KV。报告和实验均分别统计二者容量，不把新增高斯地图的存储遗漏在“同预算 memory”比较之外。

RGB_t -> Encoder -> x_t -> Semantic Predictor -> s_t
x_tilde = x_t + gate(x_t,s_t) * W s_t
x_tilde -> Frame Attention / GCA <-> Historical KV
Shared output -> Depth / Pose + Gaussian Attributes / Features
Training: differentiable lifting -> cross-view splatting -> semantic loss
Inference: causal geometry + semantic Gaussian output; no teacher required.

Research Analysis

06 · Loss Placement and Temporal Gradient Flow

训练目标由原几何损失、语义蒸馏和跨视角高斯语义损失组成。L_geo 保留基座的深度、相机及尺度约定；L_distill 监督融合前的语义预测器，使进入 memory 的向量确实对齐教师；L_cross 监督经过共享上下文和高斯读出的语义一致性。权重不预设为已验证超参数。

第一阶段冻结基座，训练轻量预测器近似教师。第二阶段用弱注入初始化融合模块，训练适配器和新预测头，再依据稳定性决定是否解冻部分 GCA。教师始终冻结。语义教师可先采用已有密集语言对齐模型；若采用 SAM+CLIP，区域到 patch 的对齐、遮挡与多尺度冲突需要显式处理。

以非锚点帧 t 为例：它的融合特征参与特殊 token 形成，随后写入 KV；在 t+k 时其密集 token 已退出近期窗口，未来帧只能读取保留状态。未来几何损失可以沿未来解码→GCA→旧 KV→旧帧融合回传。若训练缓存 detach，过去写入不会被该损失更新。

因此序列展开必须覆盖从写入到退出密集窗口再到读取的时间。只训练相邻短片段，或旧帧仍有密集特征可读时获得提升，都不足以证明远期压缩记忆改善。还需匹配一个仅在最终解码端注入语义、不写回缓存的模型。

训练可以离线使用后续图像作为监督目标，但源帧前向不能偷看它。测试仍按已到达帧因果运行。若部署时保留在线高斯优化，系统属于前馈加局部优化，需单列迭代数与端到端时延；若取消在线优化，则需验证离线训练能否保留收益。

L = L_geo + lambda_d L_distill + lambda_x L_cross
L_distill: predicted s_t versus frozen, spatially aligned teacher
L_cross: semantic rendering from predicted Gaussians versus target-view teacher
Future L_geo -> future GCA -> stored KV_t -> fusion_t
This temporal gradient requires differentiable cache handling.

Research Analysis

07 · Completed Analysis and a Synthetic Check

已完成的第一项是文献证据核对：明确区分特征附着、几何优化和历史表示学习。第二项是梯度接口检查：此前下载的 SLARM 实现中，单独特征渲染分支会对 means、quats、scales、opacities 以及相机矩阵 detach；因此可微渲染的数学表达不能替代实际配置检查。本阶段未运行 SLARM 或 LingBot-Map。

第三项是本次实际运行的一维投影高斯数值检查。固定尺度 0.25、不透明度 0.8，前景语义为 1、背景为 0；目标中心为 0，初始化中心 0.2。在 [-1,1] 上取 201 个采样点，用平方语义误差和中心有限差分计算梯度。它是简化渲染检查，不含网络、位姿、遮挡排序或 memory。

初始损失为 0.041722，中心梯度为 +0.384726，因此梯度下降推动中心朝目标移动。以 0.1 步长更新 30 次，中心约为 0.000105，损失约为 1.23×10⁻⁸。将前景和背景特征都设为 1 后，位置梯度为 0。结果只验证“特征差异经过投影可以提供位置线索”，不验证真实语义的稳定性或三维可辨识性。

这项检查也暴露了边界：区分性不足时，语义无法约束位置；即便位置梯度非零，也未必指向真实几何。完整系统还可能通过不透明度、尺度或特征变化降低损失。因此下一步必须在真实序列上同时看几何误差、完整度和语义质量。

08 · Experiments That Can Separate the Claims

先完成地图层最小实验：A0 为 LingBot-Map 初始化加无语义高斯优化；A1 增加语义但固定几何梯度；A2 在相同优化预算下开放跨视角语义到几何。A2 与 A1 比较回答语义是否有几何作用，A1 与 A0 比较语义输出能力。所有组需要相同基座预测、视图、地图大小和常规优化项。

随后完成 memory 层实验：B0 为匹配训练的原模型，B1 仅输出端融合，B2 写入前融合。B1/B2 共享教师、损失和高斯头，尽量匹配参数与算力。再加非语言视觉教师或同规模无语义分支，排除额外参数和一般高层视觉监督的解释。

主要指标为深度/点云精度与完整度、ATE/RPE；分割与开放词汇查询是第二组指标。报告短历史、密集窗口外重访、弱纹理、重复结构和未见场景，先检查多序列配对结果，不能只展示几张干净点云。输入深度若只用于监督或评价，须与推理输入明确分开。

同时测 KV 字节数、外部高斯与语义存储、峰值显存、每帧时延、关键帧语义频率和优化成本。若通过删除难点让精度提高却损害完整度，不能称重建整体改善。

判据是逐级的：A2 优于 A1 只支持语义约束地图；B2 优于 B1 且优势在远期历史条件下存在，才支持语义改善 memory；若只提高分割，则结论收缩到语义地图。失败结果同样能定位是教师不可靠、梯度不可达，还是语义对当前任务没有额外价值。

Research Analysis

09 · Contribution and Immediate Decision

当前最合理的候选贡献不是“首次把语义加到高斯”，也不是“在 LingBot-Map 上加一个头”。已有工作充分覆盖语义属性和语义地图优化。待检验的研究命题是：借助跨视角语义读出监督，让语义参与压缩历史的形成，并在匹配历史与地图预算下改善后续几何。

高斯表示在这里承担明确作用：将共享网络预测转为可跨视角验证的显式场景，使语义损失可以连接几何投影。memory 则承担跨时间信息保留，两者不互相替代。若高斯只增加工程复杂度而未提供有效约束，可以先用可微点投影验证同一假设，再决定是否保留完整高斯头。

建议先实施冻结基座的 A1/A2 对照，确认语义梯度对真实地图有帮助，再投入可微序列训练。汇报结论可以表达为：本阶段已完成机制和接口设计，下一步用分层消融验证语义收益来自地图优化还是历史表示，尚不预设它必然成立。

Reading Questions

Does LingBot-Map already predict Gaussians?

不是。需要新增可微反投影、属性预测及地图管理接口；不能把原缓存称作高斯地图。

Can semantics directly improve geometry?

只有存在可用梯度或明确几何更新路径时才可能，且须排除语义错误、特征捷径与容量变化。

What has actually been tested?

完成了论文和已有代码片段核对，以及一维合成高斯位置梯度检查；没有模型训练或真实序列结果。
