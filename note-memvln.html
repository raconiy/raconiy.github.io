MemVLN: Streaming Episodic Memory for Vision-Language Navigation

Yan Wang et al. · arXiv:2610.35066v1 · First submitted 2026-10-26 · Read version: v1

用有时间和相对位姿标注的压缩视觉记忆支持长程导航，并用轨迹摘要任务训练记忆读出。

At a Glance

  1. memory bank 保存视觉 feature、时间戳和由执行动作推算的相对位姿，容量满时合并相似相邻帧。
  2. cross-attention memory perceiver 将长历史压缩成固定数量 token，与短期观察和 StreamVGGT 几何 token 一起输入 VLM。
  3. R2R Val-Unseen 的 SR/SPL 为 55.0/50.5，真实 G1 试验从基线 16.7% 提升到 40.0%；这些是导航结果。

Paper Analysis

01 · Streaming Navigation with Episodic State

MemVLN 研究连续环境中的 vision-language navigation。策略在时刻 t 根据当前 RGB 观察、最近短期历史、任务指令和累计 episodic memory 预测动作。它把长期历史视为独立的可查询输入，而不是把整段视频无限拼接到 VLM 上。

模型由 Qwen3-VL 的视觉编码器和 LLM、冻结 StreamVGGT geometry encoder、轻量 geometry adapter 以及 memory module 组成。几何 token 提供局部空间线索，episodic token 提供跨长程路线的可恢复信息。

Mechanism

02 · Memory Bank and Compression

每次新观察产生视觉 feature f_t，并和时间 t、相对起点的位姿 z_t 一起追加进 episode-specific bank。z_t 包含 (x,y,cosθ,sinθ)，推理时只由已经执行的离散动作 dead-reckoning 得到，不使用 ground-truth pose 或外部 odometry。

bank 达到容量上限后，作者合并平均 patch-level cosine similarity 最高的相邻帧，保留有代表性的摘要，因此 token 数保持有界。存储的是 visual feature，不是已经融合几何的 hybrid feature，这让 memory 与几何 encoder 保持模块化。

z_t=(x_t,y_t,cosθ_t,sinθ_t);  bank←bank∪(f_t,t,z_t)

Mechanism

03 · Memory Perceiver and Geometry Tokens

memory perceiver 用一组可学习 query 对 bank 中的压缩 feature 做 cross-attention，输出固定数量 memory tokens m_t。LLM 输入按 prompt 分成 memory tokens、recent-history hybrid tokens、current-observation tokens 和任务指令。

StreamVGGT 为当前短期上下文产生 camera-token representations，adapter 将它与原生视觉 feature 对齐成 local hybrid tokens。于是模型可以同时读到“现在看见的局部几何”和“过去走过的路线摘要”，但两类信息进入 LLM 的接口不同。

Training

04 · Learning What the Memory Should Preserve

训练联合两个任务。navigation loss 监督下一动作，trajectory summarization loss 要求模型在遮挡部分轨迹后，仅依靠 episodic memory 恢复被遮挡的路线信息。作者把轨迹拆成多粒度 sub-trajectories，迫使 memory 保留路线级别的语义与空间线索，而不是只记住最近一帧。

两项任务使用统一 cross-entropy 目标。Qwen3-VL vision encoder、StreamVGGT 都冻结，memory module 和 geometry adapter 从零训练，LLM 用 LoRA 适配。对 LingBot-Map 的启发是可以设计 memory reconstruction 或 masked future geometry 任务，让后续帧的几何误差约束哪些语义和空间证据进入压缩状态。

L_nav=−log p(a_t^*|m_t,H_t,T); L_total=L_nav+λ_sum L_summary

Evidence

05 · Simulation Results and Ablations

R2R Val-Unseen 上 MemVLN 的 NE/OSR/SR/SPL 为 5.19/61.2/55.0/50.5，官方轨迹训练且没有额外数据。组件消融显示，加入 memory 后 R2R OSR 从 51.1 提升到 56.7，加入 geometry 后完整模型 SR 达到 55.0；trajectory-summary supervision 在 memory+geometry 基础上再带来 5.3 个百分点 SR 和 4.7 个百分点 SPL。

这些消融把三种因素拆开。memory 提供历史，geometry 提供当前空间线索，summary task 规定历史应保留路线级信息。结果支持 learned readout 的必要性，不能直接说明 memory 中保存了精确三维地图。

Evidence

06 · Long-Horizon and Real-World Evidence

在 G1 实体机器人场景中，30 个 instruction-conditioned episodes 中 24 个用于 post-training，6 个用于测试。基线成功率 16.7%，加 memory 后为 30.0%，完整 MemVLN 为 40.0%，再用 24 个示例 post-training 后为 46.7%。完整模型还把 collision rate 从基线 56.7% 降到 46.7%。

论文的长程分析按指令复杂度、回溯、长走廊和 landmark passing 分组，展示 memory 对需要回看历史路线的任务更有帮助。实体试验只在一个物理场景进行，不能据此判断所有导航环境或 reconstruction memory。

Transfer Analysis

07 · Relation to Semantic Memory in LingBot-Map

MemVLN 提供了一种训练 memory 的方法。语义 feature、时间和相对位姿先进入有界 bank，再由 query 生成固定 token；训练时用 masked trajectory 或 masked future reconstruction 要求这些 token 恢复后续需要的证据。语义在这里承担索引和路线解释，几何 encoder 负责局部空间约束。

移植到 LingBot-Map 时，可以把 object/region semantic embedding 与局部几何、观测方向和不确定度一起存储，使用 cross-attention 读出历史 token，再让 depth、pose 和 point-map loss 共同训练 memory。需要固定容量、同等参数量和相同观察窗口的对照，才能判断语义记忆改善的是几何还是只改善查询。
