Mamba3R: Fixed-Capacity Selective State Memory for Long-Sequence 3D Reconstruction

Zhenxiang Xiong et al. · arXiv:2611.04221v1 · First submitted 2026-11-03 · Read version: v1

在冻结的循环重建骨干旁加入固定容量的选择性状态记忆，并控制它对当前几何预测的反馈。

At a Glance

  1. 辅助 memory 与原生 recurrent state 以 slot 对齐，K=64 的容量不随帧数增长。
  2. selective state-space mixer 同时产生 memory-side write 和 state-side correction，读取、写入、反馈衰减分别显式控制。
  3. 在统一 reset100 协议下，ScanNet 的 CD/ATE/AbsRel 为 0.1032/0.4589/0.04666，KITTI-360 为 1.712/7.788/0.1881；这些是几何结果，不包含语义。

Paper Analysis

01 · The Long-Sequence Interface

Mamba3R 面向一个明确的工程约束：输入持续增长，但 GPU memory 和每帧吞吐要保持稳定。作者以已有的 recurrent reconstruction model 为骨干，保留原来的 depth、pose、point-map heads，只增加一个可训练 adapter。新增状态是与 backbone slots 对齐的辅助矩阵 M∈R^{L×K}，实验配置 K=64，帧数增加时容量不扩张。

论文把“记忆容量有限”和“记忆如何影响预测”分开。原生 state 继续按骨干方式传递，辅助 memory 提供额外的长期内容。后续设计分别规定它何时读取、哪一部分反馈到当前 state、哪些 slot 可以写入以及历史何时衰减。

Mechanism

02 · Selective Mixing of State and Memory

在第 t 次调用时，mixer 接收上一时刻的 state 和 memory，U_t=[M_{t−1};S_{t−1}]，输出 memory-side 与 state-side 两路特征。它沿固定 slot 顺序做 selective state-space scan。每个 slot 的步长 Δ_l、输入投影和门控由当前特征生成，因此不同 slot 可以有不同的保留与覆盖强度。

简化 recurrence 为 h_l=Ā_l h_{l−1}+B̄_l x_l，y_l=C_l h_l+D x_l，Ā_l=exp(Δ_l A)。这里 scan 的轴是继承自 backbone 的 token slot，而不是空间网格。论文借用 Mamba 的选择性更新形式，贡献在于把它接成一个既能写辅助 memory 又能修正当前 state 的重建接口。

U_t=[M_{t-1};S_{t-1}], (V_t^M,V_t^S)=B_θ(U_t); h_l=Ā_lh_{l-1}+B̄_lx_l

Mechanism

03 · Memory-Dependent Feedback

state-side 输出不会直接以全强度送入冻结 decoder。作者先用同一个 adapter 计算零 memory 响应 R_t^0，再计算带 memory 的响应与其差值 ΔR_t^M。当前候选 state 写成 S_t^+=S̃_t+R_t^0+αΔR_t^M，实验中 α=0.5，整体 adapter 缩放 γ=0.5。这样可以单独衰减“新增 memory 带来的变化”，而保留没有辅助 memory 时的 adapter 行为。

随后原生的 attention-gated commit 决定每个 slot 有多少更新到预测 state。这个 state 才被 depth、pose 和 point-map heads 读取，并继续成为下一帧的 carried state。对 LingBot-Map 来说，这提供了一个可测试的语义 memory 注入位置：语义应先影响写入和读取，再由受控残差进入几何上下文。

R_t^0=R_θ(S_{t−1},0); ΔR_t^M=R_θ(S_{t−1},M_{t−1})−R_t^0; S_t^+=S̃_t+R_t^0+αΔR_t^M

Mechanism

04 · Masked Writes and History Decay

memory-side 输出经过 binary write mask w_t 投影为增量 ΔM_t=w_t⊙P_M(w_t⊙V_t^M)，再与旧 memory 相加。外层 mask 防止未写 slot 被 projection bias 意外修改。最终状态 M_t=ρ_tM_{t−1}+ΔM_t。前 32 次有效写入不衰减，之后 ρ_t=0.8^{1/12}≈0.9816。被 mask 的写入保持 ρ_t=1，也不推进衰减计数。reset 时 state、pose 和 memory 同时恢复初始化。

这套规则把“当前证据是否值得写”与“旧证据自然变旧”区分开。论文特别说明 slot scan 的 recurrence 本身不保证跨帧稳定，ρ 控制直接保留，α 控制 memory 对当前 state 的影响，二者耦合后仍可能放大扰动。

ΔM_t=w_t⊙P_M(w_t⊙V_t^M); M_t=ρ_tM_{t−1}+ΔM_t

Training

05 · Training and Streaming Execution

训练只更新 1.28M 个 adapter 参数，冻结预训练 backbone 和任务 heads。实验使用 shared reset100 protocol，边界观测会被重复用于初始化下一段，但每张唯一图像只计一次预测。这个协议让不同 recurrent 方法在相同 segment 预算下比较 state–memory interface。

推理时每帧按固定顺序读取上一状态，计算当前候选 state，更新 heads 的预测，再执行 masked write。作者的完整机器人实验是预录 traversals 的离线回放。RTX 4060 前端平均 11.7 FPS、占用 5.1 GiB，覆盖 10 Hz 传感器时间间隔；完整耦合系统的端到端延迟仍受后端影响。

Evidence

06 · Results Under a Shared Reset Protocol

500 帧 ScanNet 上，Mamba3R 的 CD、ATE、AbsRel 分别为 0.1032 m、0.4589 m、0.04666；KITTI-360 上为 1.712 m、7.788 m、0.1881。相对 reset-matched TTT3R，作者计算 ScanNet CD、ATE、sequence-scaled AbsRel 分别下降 9.6%、7.3%、17.7%，KITTI-360 三项下降 25.1%、11.7%、23.9%。

长序列测试把 KITTI-360 运行到 1,000、2,000 和约 3,000 帧。论文指出在 no-reset ladder 中 ATE 会明显上升，而 reset100 会降低累积误差。因此结果支持固定容量 adapter 在给定 reset 协议下的几何收益，不能直接推出 reset-free 无限流的稳定性。消融还显示移除 auxiliary memory carry-over 或替换 mixer 会削弱结果。

Transfer Analysis

07 · What Transfers to Semantic Memory

对 LingBot-Map 最直接的启发是接口设计。语义向量可以与视觉/几何 token 一起写入固定 slot，write mask 可由语义新颖度、几何覆盖和置信度共同产生，memory-dependent feedback 则控制语义证据对当前几何上下文的强度。训练时可保留 adapter 与 memory 的梯度，让后续 depth/pose loss 学习哪些语义证据值得进入状态。

迁移实验应固定 slot 数、窗口长度和参数预算，比较无语义 memory、输出端语义融合和写入前语义融合。需要单独报告语义查询质量、几何精度、完整度、轨迹误差和吞吐。Mamba3R 的结果证明“固定容量状态接口可改善几何”，没有证明语义自动带来几何收益。
